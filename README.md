# Product Admin Panel

<img align="right" src="https://github.com/user-attachments/assets/19bd0906-9443-4e89-842c-51547d0a7931" width="250"/>

SPA-приложение для работы с товарами:  
авторизация, защищённый роутинг, список товаров, поиск, сортировка по цене, пагинация, выбор строк и добавление нового товара.

---



- React
- TypeScript
- Sass
- Redux Toolkit
- TanStack Table
- ESLint
- Vite

---

## Возможности

- авторизация через API
- защищённый роутинг
- сохранение сессии по логике `Remember me`
- поиск товаров по API
- сортировка по цене
- пагинация
- выбор товаров через чекбоксы
- добавление нового товара через модальное окно
- toast-уведомление после успешного добавления
- кастомное форматирование цены
- валидация формы логина
- обработка ошибок API

---

## Защищённый роутинг

Неавторизованный пользователь не может попасть на закрытые страницы приложения.  
При попытке перехода выполняется редирект на страницу логина.

На странице товаров реализованы:

- загрузка списка с API
- поиск
- сортировка по цене
- серверная пагинация
- выделение строк
- добавление товара через форму

### Поиск и сортировка

Поиск отправляется на API с debounce, чтобы не делать лишние запросы на каждый символ.  
Сортировка по цене работает через API и обновляет список товаров с учётом текущих параметров.
